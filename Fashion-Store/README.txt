Fashion Store — تعليمات التشغيل

1) افتحي index.html باستخدام Chrome أو Edge.
2) يلزم الإنترنت لتحميل الصور والخطوط ومكتبة Tailwind من مصادرها الخارجية.
3) السلة تدعم الإضافة، وزيادة/تقليل الكمية، والحذف، وحفظ محتوياتها في نفس المتصفح.
4) زر إتمام الطلب ينزّل ملفًا نصيًا بملخص الطلب. هذه نسخة واجهة أمامية تجريبية؛ لا يتم إرسال الطلب إلى صاحب المتجر ولا يوجد دفع إلكتروني أو قاعدة بيانات.
5) لاستقبال طلبات حقيقية، يلزم ربط الموقع برقم واتساب للمتجر أو بخادم/منصة طلبات وبوابة دفع.
6) الأسعار بالجنيه المصري كتنسيق مبدئي، ويجب مراجعتها وفق أسعار المنتجات الفعلية.
